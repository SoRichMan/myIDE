# LiteIDE 快捷键速查

命令面板 **Ctrl+Shift+P** 可模糊搜索全部 57 条命令（支持中英文），下面是已绑定快捷键的常用项。

## 通用

| 快捷键 | 动作 |
|---|---|
| Ctrl+Shift+P | 命令面板（搜所有命令） |
| Ctrl+, | 打开设置 |
| Ctrl+K Ctrl+S | 快捷键速查窗（应用内） |

## 文件 / 标签

| 快捷键 | 动作 |
|---|---|
| Ctrl+N | 新建文件 |
| Ctrl+P | 打开文件 / 浏览文件系统（敲路径回车跳转，或按名称过滤；可进入工程外的目录） |
| Ctrl+S | 保存 |
| Ctrl+Shift+S | 另存为 |
| Ctrl+W | 关闭当前标签 |
| Ctrl+Tab / Ctrl+Shift+Tab | 下一个 / 上一个标签 |

## 编辑

| 快捷键 | 动作 |
|---|---|
| Ctrl+Z / Ctrl+Y | 撤销 / 重做 |
| Ctrl+A / X / C / V | 全选 / 剪切 / 复制 / 粘贴 |
| Ctrl+L | 选中整行 |
| Ctrl+Shift+K | 删除整行 |
| Ctrl+Shift+D | 复制当前行到上方 |
| Ctrl+/ | 切换行注释 |
| Ctrl+F | 编辑器内查找 |
| Ctrl+H | 编辑器内替换 |

## 视图 / 导航

| 快捷键 | 动作 |
|---|---|
| Ctrl+B | 切换侧边栏 |
| Ctrl+= / Ctrl+- / Ctrl+0 | 放大 / 缩小 / 重置字号 |
| Ctrl+G | 跳转到行 |
| Ctrl+T | 工作区符号搜索 |
| F12 | 转到定义 |
| Alt+Left | 返回上一位置（跳转栈） |
| Ctrl+Shift+F | 工作区内容搜索 |

## 调试

| 快捷键 | 动作 |
|---|---|
| F5 | 开始 / 继续调试 |
| Shift+F5 | 停止调试 |
| F9 | 切换行断点 |
| F10 | 单步跳过 |
| F11 | 单步进入 |
| Shift+F11 | 单步跳出 |
| Ctrl+Shift+W | 添加到监视 |

## Git

| 快捷键 | 动作 |
|---|---|
| Ctrl+Shift+G | 打开 Git 面板 |

> 未列出的命令都在命令面板里，直接输入中文（如"保存""跳转""主题"）即可找到。
